# Karin 0.8.1

При первом запуске Karin показывает отдельный экран входа. После восстановления сохранённого аккаунта сразу открывается музыкальная библиотека.

Пункт «Проверить обновления» доступен до входа в аккаунт. Для Flatpak, подключённого к подписанному репозиторию Karin, приложение использует системный механизм установки. В Native-версии можно просмотреть изменения и открыть страницу выпуска.

В обычном меню остались пользовательские действия. Инструменты диагностики доступны через `--diagnostics`.
