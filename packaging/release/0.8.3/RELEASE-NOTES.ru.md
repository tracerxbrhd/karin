# Karin 0.8.3

Karin — независимый нативный клиент Яндекс Музыки для Linux.

- Диалог обновлений показывает версии, заметки выпуска и состояние подтверждения Flatpak.
- Из личного плейлиста можно удалить выбранное вхождение трека, в том числе дубликат. Очередь и воспроизведение сохраняются.
- В разделе «Интеграции» можно включить передачу текущего трека локальному Discord. По умолчанию эта настройка выключена.
- Публичные ссылки на треки, альбомы и исполнителей доступны в меню. Команды клавиатуры собраны в окне «Сочетания клавиш».

## Установка и обновление

- **Flatpak.** Откройте `karin-0.8.3-x86_64.flatpak` в менеджере приложений или выполните `flatpak install --user ./karin-0.8.3-x86_64.flatpak`. Пакет подключает подписанный канал Karin и использует GNOME Platform 50.
- **Native.** Распакуйте `karin-0.8.3-linux-x86_64.tar.gz` и запустите `./run-karin`. [Системные зависимости](https://github.com/tracerxbrhd/karin/blob/master/docs/BUILDING.md#fedora-prerequisites)

Для перехода с 0.8.2 используйте Discover, GNOME Software или `flatpak update --user io.github.tracerxbrhd.Karin`, если Karin установлен для текущего пользователя. Менеджер приложений или Flatpak запрашивает согласие на доступ к Discord IPC. Данные пользователя хранятся отдельно от пакета.

[Полные соответствующие исходники 0.8.3](https://github.com/tracerxbrhd/karin-source/releases/download/v0.8.3/karin-0.8.3-source.tar.gz).

Доступ к музыке зависит от сервиса и аккаунта. Лицензия Karin — GPL-3.0-or-later.
