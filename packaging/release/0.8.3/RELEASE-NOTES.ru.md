# Karin 0.8.3

Karin — независимый нативный клиент Яндекс Музыки для Linux.

## Установка и обновление

- **Flatpak.** Откройте `karin-0.8.3-x86_64.flatpak` в менеджере приложений или выполните `flatpak install --user ./karin-0.8.3-x86_64.flatpak`. Пакет подключает подписанный канал Karin и использует GNOME Platform 50.
- **Native.** Распакуйте `karin-0.8.3-linux-x86_64.tar.gz` и запустите `./run-karin`. [Системные зависимости](https://github.com/tracerxbrhd/karin/blob/master/docs/BUILDING.md#fedora-prerequisites)

Для существующей пользовательской установки через канал Karin доступна команда `flatpak update --user io.github.tracerxbrhd.Karin`. Подтверждение новых разрешений запрашивает системный менеджер приложений или Flatpak. Данные пользователя хранятся отдельно от пакета.

[Полные соответствующие исходники 0.8.3](https://github.com/tracerxbrhd/karin-source/releases/download/v0.8.3/karin-0.8.3-source.tar.gz).

Доступ к музыке зависит от сервиса и аккаунта. Лицензия Karin — GPL-3.0-or-later.
